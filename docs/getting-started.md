# Getting Started

## Prerequisites

- Terraform installed and available on your PATH.
- Python 3.10+ with the project virtual environment activated.
- AWS credentials configured for the target account.
- Infracost installed if you want cost estimates.

## Run the Wizard

```bash
source .venv/bin/activate
python cli-wizard/wizard.py
```

## Destroy Resources

```bash
python cli-wizard/wizard.py --destroy
```

## Validate Locally

```bash
terraform init -backend=false
terraform validate
pytest tests/
```

## Notes

- `terraform.tfvars` is generated by the wizard and should not be committed.
- Keep DynamoDB point-in-time recovery disabled for free-tier testing unless you explicitly need backups.
