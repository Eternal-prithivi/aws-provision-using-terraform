# Smart AWS Infrastructure Provisioning System

A modular, self-service AWS infrastructure provisioning system built with Terraform — featuring a Python CLI wizard, a configurable Policy and Risk Engine, Infracost cost estimation, and automated drift detection.

**Built for**: Small teams, solo developers, students learning DevOps
**Project level**: Advanced student / internship — close to professional-grade system design
**AWS cost**: $0 if you follow the safety rules below

---

## What This Does

1. You run a CLI wizard
2. You select services and environment
3. The Policy and Risk Engine checks your config for security/cost violations
4. Infracost shows your estimated monthly cost before deploying
5. You confirm, and Terraform provisions your AWS infrastructure
6. A daily job monitors for infrastructure drift

## Policy and Risk Engine

Rules are defined in `policy-engine/rules.yaml`. Add new rules without touching Python code.

**Block-level rules** (stop deployment):
- Public S3 bucket
- Open SSH port (22) to 0.0.0.0/0
- Open RDP port (3389) to 0.0.0.0/0
- IAM wildcard permissions

**Warning-level rules** (warn, ask confirmation):
- Missing S3 encryption
- Non-free-tier EC2 instance type
- Missing resource tags
- CloudTrail disabled

## ⚠️ AWS Cost Safety Rules

**This project uses real AWS. Follow these rules to stay at $0:**

1. Set a **$1 billing alert** in AWS console immediately after account creation
2. **Always run `terraform destroy`** after every test session
3. **Never provision a NAT Gateway** during development (~$32/month)
4. Use **t2.micro** for EC2 testing (free tier eligible)
5. Check the **AWS billing dashboard** once per week

## CI/CD (GitHub Actions)

### On every push/PR
- `pytest tests/` — tests must pass before anything else
- `terraform validate` — syntax check
- `terraform fmt -check` — formatting check
- `terraform plan` — preview changes

### On every PR
- Infracost posts a cost diff comment showing how the change affects monthly cost

### Daily (cron)
- Drift detection runs and alerts if real AWS infrastructure diverges from state

**GitHub Actions secrets required:**
```
AWS_ACCESS_KEY_ID
AWS_SECRET_ACCESS_KEY
INFRACOST_API_KEY
```
