## 🚀 MANDATORY STARTUP FLOW

When a new chat or agent session starts, execute in this exact order:

```
1. READ  → AI_MASTER.md       (this file — understand the protocol)
2. READ  → AI_CONTEXT.md      (project architecture, tech stack, module map)
3. READ  → AI_RULES.md        (what you MUST and MUST NOT do)
4. READ  → PROGRESS.md        (current phase, completed tasks, next tasks)
5. READ  → DECISIONS.md       (locked-in architecture decisions — do not revisit)
6. READ  → SCRATCHPAD.md      (if mid-task state exists, resume from here)
7. CONFIRM → State the current phase and next task before writing any code
```

**Do not skip steps. Do not write code before completing all 7 steps.**

## 📋 TASK EXECUTION PROTOCOL

For every task:

### Before Writing Code
- [ ] Confirm which PHASE you are in (see PROGRESS.md)
- [ ] Confirm the task aligns with the current phase
- [ ] Check DECISIONS.md — never reopen settled decisions
- [ ] State your implementation plan in 3–5 bullet points first
- [ ] Identify which module/component is being touched

### While Writing Code
- [ ] Follow Python PEP 8 — type hints required on all functions
- [ ] Follow Terraform best practices — all modules must have variables.tf + outputs.tf
- [ ] Write tests in the same session as the code — never defer testing
- [ ] Use the rules engine YAML pattern for policy rules — never hardcode
- [ ] Never hardcode AWS credentials, region, or account IDs

### After Completing Code
- [ ] Update PROGRESS.md — move task from "In Progress" to "Completed"
- [ ] Add a new entry to AUDIT_LOG.md using AGENT_SESSION_TEMPLATE.md format
- [ ] Update SCRATCHPAD.md if work is incomplete (mid-task state)
- [ ] Clear SCRATCHPAD.md if task is fully done
- [ ] State what the next task is

## ⚠️ COST SAFETY PROTOCOL

**This project uses a real AWS account. Follow these rules every session:**

1. **NEVER** leave resources running after a test session
2. **ALWAYS** run `terraform destroy` before ending work
3. **NEVER** provision a NAT Gateway during development (costs ~$32/month)
4. **ALWAYS** use t2.micro for EC2 during testing or free tier eligible instance only
5. **VERIFY** AWS billing dashboard shows $0 before closing session
6. AWS Billing alert is set at **$1** — if you receive an alert, destroy immediately

## 🎯 DEFINITION OF DONE

A task is only done when ALL of the following are true:

- [ ] Code is written and follows project conventions
- [ ] Unit tests written and passing
- [ ] Edge cases tested (null input, invalid input, missing tools)
- [ ] `terraform validate` passes for any Terraform changes
- [ ] `pytest tests/` passes with no failures
- [ ] PROGRESS.md updated
- [ ] AUDIT_LOG.md updated
- [ ] AWS resources destroyed if any were provisioned
